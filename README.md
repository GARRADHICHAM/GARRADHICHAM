👋 Bonjour, je suis Hicham, ingénieur IA et data. Je conçois et mets en production des systèmes d'IA : RAG, agents LLM, modèles de machine learning et pipelines de données, sur GCP et AWS.

🎓 Diplômé du Master 2 MIAGE, Intelligence Artificielle Appliquée (Université Côte d'Azur).

### 🚀 Ce que j'ai construit

- **Système RAG en production** : extraction de filtres par NLP, retrieval sur PostgreSQL, génération via Gemini avec garde-fous et évaluation des réponses, exposé par une API FastAPI et déployé en CI/CD.
- **Pipeline de données retail incrémental sur GCP** : ELT horaire (Cloud Run Jobs, Cloud Scheduler), chargement idempotent dans BigQuery (MERGE, SCD2), environ 200 tests, mypy strict, infrastructure en Terraform et alertes de fraîcheur.
- **Plateforme multi-agents** : 6 agents LLM spécialisés orchestrés avec Google ADK sur Cloud Run, données dans BigQuery, monitoring et observabilité.
- **Serveur MCP** : 5 outils exposés à un agent LLM et connectés à une API hôtelière réelle, en TypeScript.
- **EthicAI** : extension VS Code d'audit éthique des modèles (biais, explicabilité SHAP/LIME, conformité à l'AI Act), co-fondée en équipe.

### 🌟 Expérience

4 expériences en data et IA depuis 2023 (fintech, imagerie médicale, mobilité, industries culturelles), dont une mission freelance livrée en production sur AWS.
